| 항목 | 내용 |

## 1. 목적

C# 본 빌드에 들어가기 전, **빠르게 전체 흐름을 검증**한다. 본 Phase가 완료되면 다음이 가능해야 한다.

- 매장 PC가 부팅하면 자동 실행되어 Server C에 WS로 접속한다.
- 주방·카운터에 적합한 print_job이 USB 프린터로 출력된다.
- 1개 매장에서 1주일 무중단 운영하며 발견된 이슈가 PRD/코드에 반영된다.

> ⚠️ 이 단계는 **양산 빌드가 아니다**. PyInstaller로 단일 .exe를 만들어 베타 매장에만 설치한다. 코드 서명, 자동 업데이트, 다국어 UI 등은 Phase 5에서 다룬다.

## 3. 세부 작업 항목

### 3.1 프로젝트 초기화

- [ ] Python 3.11+ 가상환경
- [ ] 의존성: `websockets`, `python-escpos`, `pystray`, `pillow`, `pywin32`(Print Spooler용), `loguru` 또는 stdlib `logging`
- [ ] requirements.txt + lockfile

### 3.2 WebSocket 클라이언트

PRD §7.4.

- [ ] WSS 연결 (`wss://barorez.com/printsvc/ws`)
- [ ] 첫 메시지로 `type=auth` 전송 (`client_id`, `token`, `capabilities`, `app_version`, `last_known_job_id`)
- [ ] `auth_ok` 수신 후 작업 수신 루프 진입
- [ ] ping/pong 30초, 끊김 시 지수 백오프 재접속 (1s → 30s → 5min 상한)
- [ ] `last_known_job_id`는 로컬 SQLite 또는 파일에 영속화

### 3.3 페이로드 → ESC/POS 포맷터

PRD §7.2 페이로드 스펙 기준.

- [ ] 헤더: 매장명, 출력 종류(주방/카운터/바), 테이블, 주문 시각
- [ ] 메뉴 라인: 메뉴명 + 수량 + 옵션
- [ ] 메모(`memo`) 라인
- [ ] 푸터: 구분선, cut 명령
- [ ] 한글 인코딩: CP949/EUC-KR 시도, 프린터 코드페이지 설정값에 맞춰 select
- [ ] 폭: 80mm (48컬럼) 기준 1차 구현, 58mm는 옵션화

### 3.4 USB 프린터 출력

PRD §4.3 — Windows Print Spooler raw 모드 우선.

- [ ] `win32print.OpenPrinter()` → `StartDocPrinter(RAW)` → `WritePrinter(bytes)` → `EndDocPrinter()`
- [ ] 프린터 이름은 설정 파일에서 로드 (capability별로 분리)
- [ ] 오류 분류 (PRD §8.6):
  - `PRINTER_OFFLINE`: OpenPrinter 실패
  - `PRINTER_OUT_OF_PAPER`: GetPrinter 상태 비트 검사
  - `UNSUPPORTED_ENCODING`: encode 예외
  - `UNKNOWN`: 그 외
- [ ] python-escpos는 폴백 옵션으로만 보관 (libusb 의존성 회피)

### 3.5 ACK 송신

- [ ] 성공 시 `{ "type":"ack", "job_id":..., "status":"printed", "printed_at": ISO8601 }`
- [ ] 실패 시 `error_code` + `error_message` 포함
- [ ] 중복 수신 (같은 job_id) → 출력 생략, ACK만 회신 (PRD §8.4)

### 3.6 트레이 UI

PRD §4.3.

- [ ] `pystray` 아이콘, 상태별 색상 (정상/연결끊김/오류)
- [ ] 메뉴: "최근 출력 50건", "상태 확인", "재연결", "로그 폴더 열기", "버전 정보", "종료"
- [ ] "최근 출력 50건" → Tkinter 또는 가벼운 윈도우로 출력 로그 표시

### 3.7 자동 시작

- [ ] HKCU\Software\Microsoft\Windows\CurrentVersion\Run 레지스트리 등록
- [ ] 또는 시작 폴더에 .lnk 생성
- [ ] 인스톨러(또는 첫 실행 시) 자동 등록

### 3.8 로컬 로그

PRD §9.2.

- [ ] `%LOCALAPPDATA%\barorez-printer\logs\YYYY-MM-DD.log`
- [ ] 30일 보관, 자동 삭제

### 3.9 PyInstaller 빌드

- [ ] `pyinstaller --onefile --noconsole --icon barorez.ico --add-data ...`
- [ ] 결과물 크기/실행 검증
- [ ] Windows Defender SmartScreen 경고 발생 시 점주 안내 문구 준비

### 3.10 베타 매장 배포

- [ ] 베타 매장 선정 (의사결정 필요 — 사용자가 보유한 매장 목록에서)
- [ ] Admin UI에서 client 등록 → token 발급 (Phase 4 전이지만 임시 SQL 직접 INSERT로 대체 가능)
- [ ] 점주에게 설치 가이드 전달, 원격 설치 지원
- [ ] 1주일 운영 — 매일 로그 확인 + 이슈 기록

### 3.11 베타 결과 회수

- [ ] 출력 지연(p50/p95) 측정
- [ ] 한글 깨짐, 컬럼 정렬 이슈 정리
- [ ] 프린터 모델별 호환성 메모
- [ ] PRD §14.1 위험 항목 검증 및 보강

## 4. 작업 순서

1. 프로젝트 초기화 + 의존성 (D1)
2. 로컬 환경에 영수증 프린터 1대 확보 (없으면 시뮬레이터 또는 RAW byte 파일 출력으로 대체)
3. ESC/POS 포맷터 + Print Spooler raw 출력 (D3, D4) — 단독 스크립트로 가짜 페이로드 출력 시험
4. WS 클라이언트 + 인증 + 작업 수신 (D2)
5. ACK 회신 + 중복 방지 (D8)
6. 트레이 UI + 로그 (D5, D6)
7. PyInstaller 빌드 (D9)
8. 베타 매장 설치 + 1주일 운영 (D10, D11)
9. 회수된 이슈 정리
