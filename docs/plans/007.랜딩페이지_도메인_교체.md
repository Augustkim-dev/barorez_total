# 007. 랜딩페이지 외부 링크 도메인 교체 (epicque.com → barorez.com)

작성일: 2026-05-18
작성자: August Kim

## 배경 (Context)

`web/public_html/index.html` 마케팅 랜딩 페이지에 구 도메인 `qrorder.epicque.com` 을 가리키는 절대 URL 이 4군데 남아 있다. 운영 도메인은 `barorez.com` 으로 이전됐고, 랜딩에서 외부로 빠지는 모든 링크/이미지가 현재는 구 도메인을 호출하므로 사용자가 클릭/로딩 시 잘못된(또는 곧 사라질) 호스트로 향한다.

**범위 한정**: 이번 작업은 **랜딩 페이지 단 한 파일** (`web/public_html/index.html`) 에만 적용한다. 그 외 `app/`, `market/`, `mng/`, `cfg/` 등의 PHP 소스 안에 epicque 참조가 더 있을 수 있으나 이번 작업에서는 다루지 않는다 (필요 시 별도 작업으로 분리).

## 변경 대상 (총 4건 — 모두 같은 파일)

파일: `web/public_html/index.html`

## 구현 방법

`Edit` 툴 4회로 각 라인을 정확히 치환한다. 각 `old_string` 은 라인 전체를 사용해서 의도치 않은 일치를 피한다. `replace_all` 은 쓰지 않는다 (라인 984 는 경로까지 바뀌어서 단순 일괄 치환이 불가능).

치환 순서는 위 표 그대로 (위→아래, 라인 번호 변동 없음 — 한 줄 안에서 문자열만 바뀜).

## 검증

작업 대상이 정적 HTML 한 파일이고 빌드 단계가 없으므로 다음으로 충분하다.

1. **정적 검증**: `web/public_html/index.html` 안에 `epicque` 문자열이 남아 있지 않은지 grep → 0건이어야 함.
2. **링크 동작 확인** (운영/스테이징 브라우저):
   - 헤더/푸터의 맛집바로 로고 이미지가 깨지지 않고 표시되는지 (`https://barorez.com/design/img/logo.svg` 200 응답)
   - "가맹점 등록하기" 버튼 클릭 → `https://barorez.com/market/join.php` 정상 로드
   - "회원가입하기" 버튼 클릭 → `https://barorez.com/app/auth/join.php` 정상 로드
3. **세션 영향 없음 확인**: 정적 HTML 이라 `cfg/lib.inc.php` 부트스트랩을 거치지 않으므로 세션/DB 부수효과 없음.
