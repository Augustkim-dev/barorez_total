# 008. 랜딩페이지 PG 신청용 정보 추가 (사업자정보 + 약관 + 환불정책 초안)

작성일: 2026-05-18
작성자: August Kim

## 배경 (Context)

맛집바로 서비스에 PG (Payment Gateway) 를 신청하기 위해 PG 심사기관 요구 사항을 랜딩 페이지에서 공개적으로 충족시키는 작업.

PG 심사 표준 요구 항목:
1. 사업자정보 (법인명/대표/사업자등록번호/통신판매업 신고번호/주소/고객센터)
2. 이용약관 링크
3. 개인정보처리방침 링크
4. 환불(취소/반품) 정책 링크
5. (상품등록) — 이번 범위 제외 (사용자 명시)

현재 `web/public_html/index.html` 푸터는 로고+카피라이트 한 줄만 있어 PG 심사를 충족하지 못함. 이번 작업으로 푸터를 좌우 2열로 확장하여 위 정보를 모두 노출. 환불정책은 사용자가 직접 Google Sites 로 옮길 초안 마크다운을 동봉.

## 구현 결정 사항

- **푸터 레이아웃**: 좌우 2열 (Recommended) — 좌측 로고+슬로건+카피라이트, 우측 약관 4링크+사업자정보 6행
- **약관 링크**: 모두 `target="_blank" rel="noopener"`, `|` 구분자
- **환불정책 placeholder**: `href="#"` + `data-todo="refund-url"` 어트리뷰트로 grep 추출 용이성 확보
- **사업자정보 의미 마크업**: `<dl>/<dt>/<dd>` 사용 (검색엔진/스크린리더 친화)
- **반응형**: 768px↓ 1열 세로 적층, 가운데 정렬 (모바일 가독성)
