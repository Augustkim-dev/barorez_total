## 2. 의존 관계 도식

```
Phase 1 ─────────────────────────────────────────────► (DB, PHP API 기반)
   │
   ▼
Phase 2 ─────────────────────────────────────────────► (Server C 가용)
   │
   ├──────────────────────────────┐
   ▼                              ▼
Phase 3 (Python 베타)        Phase 4 (Admin UI)
   │                              │
   │ (베타 학습 회수)             │ (client 등록 GUI 가용)
   ▼                              │
Phase 5 (C# 본 빌드) ◄────────────┘
   │
   ▼
Phase 6 (운영/확장)
```

- Phase 3과 Phase 4는 Phase 2 완료 후 **병렬 진행 가능**하다.
- Phase 5는 Phase 3의 베타 학습과 Phase 4의 Admin UI 두 가지를 입력으로 받는다.
