## 1. 한 줄 요약
헤드리스 데몬을 **데몬화 + 가시화**. 트레이 아이콘 3색 상태 표시(연결됨/접속중·끊김/오류), 메뉴 5종(최근 출력·상태 확인·재연결·로그 폴더·버전·종료), 로그 일별 로테이션 30일 보관, HKCU\\Run 자동 시작 등록 CLI. 운영 데이터 경로는 `%LOCALAPPDATA%\\barorez-printer\\`, 개발 모드(저장소 안)에서는 `client_python/` 폴백.

## 2. 신규 산출물

### 2.1 코드

### 2.2 확장
| 파일 | 변경 |
|---|---|
| `client_python/src/logger.py` | `TimedRotatingFileHandler(when='midnight', backupCount=30)` 본격. `current.log` → 자정 회전 시 `current.log.YYYY-MM-DD`. `RecentBuffer` (deque maxlen=50) 추가 — 트레이 "최근 출력" 메뉴 데이터 소스. `record(job_id, printer_type, status, detail)` 헬퍼 |
| `client_python/src/ws_client.py` | `run(..., on_status=callback)` 추가. 상태 5종 (`connecting`/`connected`/`disconnected`/`auth_failed`/`print_failed`) emit. print_job 처리 시 `logger.record(...)` 호출로 ring buffer 적재 |
| `client_python/tools/run_client.py` | 트레이 + asyncio 통합 진입점으로 재작성. `--no-tray` 헤드리스 모드. 트레이는 별도 daemon thread, 종료/재연결 신호는 `call_soon_threadsafe` 로 asyncio 측에 전달 |
| `client_python/requirements.txt` | `pystray>=0.19`, `Pillow>=10` 추가 |

## 3. 검증

### 3.1 단위
- `paths.resolve(explicit)` — explicit 파일명 유지, state/logs 폴더 동일 부모 기준.
- `paths.resolve(None)` — LOCALAPPDATA 비존재 환경에서 개발 폴백(`client_python/`) 선택.
- `logger.setup` — StreamHandler + TimedRotatingFileHandler 2개 등록, `current.log` 생성.
- `RecentBuffer` — `record()` 호출 순서의 역순으로 `snapshot()[0]` 반환 (최신 먼저).
- `tray._make_icon()` — 4개 상태별 64x64 RGBA 이미지 생성 OK.
- `install_autostart.status()` / `_build_command(None)` — 명령 문자열에 `run_client` 포함, 미설치 상태 rc=1 정상.
- `ws_client.run` signature — `on_status` 인자 노출.

### 3.2 수동 (사용자 액션, D015 진입 전)
- `python -m client_python.tools.run_client` — 트레이 아이콘 표시, 우클릭 메뉴 5종 동작 확인.
- 운영 주문 1건 발생 시 트레이 아이콘 잠시 초록 유지 + 메뉴 "최근 출력" 에 1건 추가 확인.
- 의도적 Wi-Fi 단절 → 아이콘 노랑, 복구 → 초록 전환 확인.
- `python -m client_python.tools.install_autostart --install` → 재부팅 후 자동 기동, `--uninstall` 로 해제 확인.

## 5. 알려진 한계 (D015 / Phase 5 로 이관)

- 트레이 아이콘은 Pillow 즉석 생성 단색 원 — 디자인 교체는 Phase 5 본 빌드 시점.
- `install_autostart` 의 명령은 venv 의 pythonw.exe 절대 경로를 박는 형태. PyInstaller .exe 가 만들어지면 그쪽으로 자동 갱신 (D015).
- "상태 확인" / "버전 정보" 다이얼로그는 MessageBoxW 단순 호출 — 폰트·아이콘 커스텀 없음 (Phase 5).

## 6. 변경 영향도 점검

- `client_python/` 내부 변경만 — DB/PHP/Server C 영향 0건.
- 외부 의존성 신규 2건 (`pystray`, `Pillow`) — pure Python. `Pillow` 는 PyInstaller 빌드 크기 증가 요인 (~5MB) — D015 에서 측정.
