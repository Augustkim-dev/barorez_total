# 007. 랜딩페이지 외부 링크 도메인 교체 (epicque.com → barorez.com)

작업일: 2026-05-18
작업자: August Kim
계획서: [docs/plans/007.랜딩페이지_도메인_교체.md](../plans/007.랜딩페이지_도메인_교체.md)

## 요약

마케팅 랜딩 페이지 (`web/public_html/index.html`) 에 남아 있던 구 도메인 `qrorder.epicque.com` 절대 URL 4건을 새 운영 도메인 `barorez.com` 으로 교체. "회원가입하기" 버튼 한 건은 barorez 의 디렉토리 구조에 맞춰 경로(`/auth/login.php` → `/app/auth/join.php`)도 함께 정정.

## 적용 변경

파일: `web/public_html/index.html` (단일 파일)

| 라인 | 종류 | 변경 |
|------|------|------|
| 767 | `<img src>` (헤더 로고) | `qrorder.epicque.com/design/img/logo.svg` → `barorez.com/design/img/logo.svg` |
| 976 | `<a href>` (가맹점 등록하기) | `qrorder.epicque.com/market/join.php` → `barorez.com/market/join.php` |
| 984 | `<a href>` (회원가입하기) | `qrorder.epicque.com/auth/login.php` → `barorez.com/app/auth/join.php` (경로 보정) |
| 994 | `<img src>` (푸터 로고) | `qrorder.epicque.com/design/img/logo.svg` → `barorez.com/design/img/logo.svg` |

## 사전 확인 사항

- barorez 측 `web/public_html/design/img/logo.svg` 파일 존재 확인 → 로고 두 건은 도메인만 교체로 OK
- barorez 측 `web/public_html/market/join.php` 존재 확인 → 가맹점 등록 경로 그대로 유지
- barorez 측 루트에 `/auth/` 디렉토리 없음 → 회원가입 버튼은 `/app/auth/join.php` 로 경로까지 변경 (사용자 컨펌)

## 검증 결과

- `grep -i "epicque" web/public_html/index.html` → 0건 (잔존 없음 확인)
- 운영 환경 브라우저 동작 확인은 배포 후 별도 검증 필요 (헤더/푸터 로고 표시, 두 CTA 버튼 이동 정상 여부)

## 범위 제한

이번 작업은 **랜딩 페이지 한정**. PHP 소스 (`app/`, `market/`, `mng/`, `cfg/` 등) 에 잔존할 수 있는 epicque 참조는 이번 범위 밖. 사용자가 명시적으로 랜딩 페이지로 범위를 좁혔으며, 필요 시 별도 작업 단위로 처리한다.
