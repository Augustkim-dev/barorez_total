## 4. 운영 절차 (1주 동안 매일)

### 4.1 매일 09:00 점검
- `docs/operations/베타_운영일지.md` 의 당일 블록 추가:
  ```sql
  -- 어제 분 집계
  SELECT
    DATE(created_at) AS d,
    COUNT(*)                                       AS total,
    SUM(status='printed')                          AS printed,
    SUM(status='failed')                           AS failed,
    SUM(status='queued')                           AS still_queued,
    AVG(TIMESTAMPDIFF(SECOND, created_at, printed_at)) AS avg_delay_s
  FROM print_job_t
  WHERE created_at >= CURDATE() - INTERVAL 1 DAY
    AND created_at <  CURDATE()
  GROUP BY d;
  ```
- Server C 로그 (pino-roll) 에서 `event=auth_ok` / `event=replaced` / `event=client_dropped` 카운트 확인.
- 트레이 색상 빨강 진입 횟수는 매장 PC `dist/logs/current.log` 의 `print_failed` 발생 횟수.
