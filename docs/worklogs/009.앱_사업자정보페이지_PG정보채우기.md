작업자: August Kim
계획서: [docs/plans/009.앱_사업자정보페이지_PG정보채우기.md](../plans/009.앱_사업자정보페이지_PG정보채우기.md)

## 요약

`https://barorez.com/app/customer/info.php` 의 뷰 파일에 박혀 있던 더미 데이터(잘못 박힌 "예약일시" 항목 + 더미 사업자등록번호/주소/이메일/연락처) 를 008 에서 확정된 실데이터로 교체. 동일 화면에 약관/정책 섹션을 신규 추가하여 PG 신청용 정보 노출의 랜딩 페이지와 정합성을 맞춤.

## 적용 변경

파일: `web/public_html/app/views/customer/info.php` (뷰 단일 파일)

### 섹션 1 — 회사 정보 (5행)
| 항목 | 값 |
|------|------|
| 법인명 | (주)코로코 (Coroco Co., Ltd.) |
| 대표 | 임재득, 임영묵 |
| 사업자등록번호 | 126-86-64275 |
| 통신판매업 | 제 2015-경기광주-0225 호 |
| 주소 | 경기도 광주시 경충대로 1845 (장지동) |

작업 전의 "예약일시 2025.07.16 ..." 행은 회사 정보 페이지와 무관한 잘못 박힌 더미였으므로 삭제.

### 섹션 2 — 고객센터 (2행)
- 운영시간: 그대로 유지 (`오전 9시 ~ 오후 6시 / 점심 12:30~13:30`)
- 연락처: `1234-1234` → `1660-0404`
- 이메일(`test1234@test.com`) 행: 미확정 상태이므로 삭제 (확정 시 한 줄 재추가)
- 컨테이너에 `border-bottom` 추가하여 섹션 3 과 시각 구분

### 섹션 3 — 약관 및 정책 (신규, 4행)
- 헤더 아이콘: 인라인 SVG (문서 아이콘) — 외부 svg 파일 의존 없음
- dt(약관명) + dd("보기 ↗" 링크), `target="_blank" rel="noopener"`

| 항목 | URL |
|------|------|
| 이용약관 | https://sites.google.com/view/qrorder-term |
| 개인정보처리방침 | https://sites.google.com/view/qrorders-privacy |
| 위치정보 이용약관 | https://sites.google.com/view/qrorder-qeo-term |
| 환불정책 | https://sites.google.com/view/barorez-refund |

## 검증 결과

### 정적 grep
- ✅ 더미 5종 잔존 0건 (`124-123456761654`, `test1234@test.com`, `1234-1234`, `테헤란로 0길`, `예약일시`)
- ✅ 신규 6항목 + URL 4종 모두 노출
- ✅ 랜딩 푸터(`web/public_html/index.html`) 와 동일 키들 두 파일에 일관 존재 — cross-check 통과

### 시각 검증 (배포 후 권장)
- `https://barorez.com/app/customer/info.php` 접속 시 3개 섹션(회사 정보 / 고객센터 / 약관 및 정책) 정상 표시
- 약관 링크 4개 클릭 시 새 탭에서 외부 Google Sites 정상 열림
- 앱 웹뷰(모바일 폭) 에서 dt/dd 정렬 회귀 없음 — 기존 `customer_list` 클래스 그대로 사용

## 범위 제한

- 작업 대상 단일 파일. PHP 부트스트랩/세션/DB 영향 없음.
- `market/` 점주 페이지의 사업자 정보 페이지 — 존재/콘텐츠 미확인. PG 심사 범위 보강이 필요하면 별도 작업으로 분리.
