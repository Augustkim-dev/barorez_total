# 008. 랜딩페이지 PG 신청용 정보 추가

작업일: 2026-05-18
작업자: August Kim
계획서: [docs/plans/008.랜딩페이지_PG신청용_정보추가.md](../plans/008.랜딩페이지_PG신청용_정보추가.md)

## 요약

맛집바로 PG 신청 사전 조건을 랜딩 페이지에서 충족하도록, 푸터를 좌우 2열로 재구성하여 사업자정보 + 약관 링크 4개를 노출. 환불정책은 사용자가 Google Sites 로 직접 옮길 초안 마크다운을 별도 산출물로 동봉. 상품등록은 사용자 요청으로 이번 범위에서 제외.

## 적용 변경

### 1. `web/public_html/index.html`

**(1) 푸터 CSS 섹션 확장**
- 기존 가운데 정렬, 단일 컬럼 → `display: grid; grid-template-columns: 1fr 1.2fr; gap: 48px;` 좌우 2열
- 신규 클래스: `.footer-left`, `.footer-right`, `.footer-tagline`, `.footer-copyright`, `.footer-links`, `.footer-divider`, `.footer-biz`, `.footer-biz-row`
- 다크 배경 위 가독성 위해 색상 단계화 (`rgba(255,255,255, 0.35/0.5/0.65/0.7)`)

**(2) `@media (max-width: 768px)` 블록에 푸터 반응형 추가**
- 1열 세로 적층, 가운데 정렬
- 사업자정보(`<dl>`)는 모바일에서도 라벨/값 가로 정렬 유지 (`inline-block + text-align: left` 컨테이너)

**(3) `<footer>` 마크업 좌우 2열 구조로 재작성**
- 좌측: 로고 + "지도에서 찾고 바로 주문하는 맛집 서비스" 슬로건 + 카피라이트
- 우측 상단: 약관 4링크 (이용약관 · 개인정보처리방침 · 위치정보 이용약관 · 환불정책)
  - 외부 약관 3개는 사용자 제공 Google Sites URL 적용
  - 환불정책은 `href="#" data-todo="refund-url"` placeholder
- 우측 하단: `<dl>` 기반 사업자정보 6행
  - 법인명 / 대표 / 사업자등록번호 / 통신판매업 / 주소 / 고객센터

### 2. `docs/policies/refund-policy-draft.md` (신규)

한국 전자상거래법 기반 환불정책 초안. Google Sites 에 그대로 복붙 가능. 다음 섹션 포함:

1. 기본 원칙 (법령 근거 명시)
2. 주문 유형별 환불 기준
   - 매장 QR 주문 — 선결제(PREPAY): 상태별 4단계 환불 가능 여부
   - 매장 QR 주문 — 후결제(POSTPAY): 오결제·중복결제 대상
   - 예약 선결제(PREPAID): 가맹점 패널티 정책 + 기본 기준 (24h 전 / 2h 전 / 노쇼)
3. 환불 신청 방법 (앱 · 매장 · 고객센터 3경로)
4. 환불 불가 사유 + 예외 (전액 환불 케이스)
5. 환불 처리 기간 (결제 수단별 영업일 기준)
6. 분쟁 해결 (소비자원·전자거래분쟁조정위·공정위 1372)
7. 사업자 정보
8. 약관 변경 공지 규정

## 범위 제한

- 작업 대상은 **랜딩 페이지 한 파일** + 환불정책 초안 1 파일.
- `app/`, `market/`, `mng/` 의 푸터/약관 일관성은 별도 후속 작업으로 분리.

## 후속 작업 (사용자 확정 시 한 줄 교체)

1. 고객센터 전화번호 `1855-0759` 컨펌 또는 교체
2. 고객센터 이메일 추가 (있다면)
3. 환불정책 Google Sites 게시 후 URL 확보 → `data-todo="refund-url"` 위치 `href` 교체
