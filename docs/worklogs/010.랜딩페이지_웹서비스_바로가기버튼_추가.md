# 010. 랜딩페이지 웹 서비스 바로가기 버튼 추가

- **작업일자:** 2026-06-12
- **대상 파일:** `web/public_html/index.html` (단일 정적 HTML, 빌드 단계 없음)
- **연결 URL:** `https://barorez.com/app`

## 배경
랜딩페이지에는 앱스토어(구글/애플) 다운로드 링크만 있고, 앱 설치 없이 웹 서비스로 바로 진입하는 경로가 없었다. 사용자가 즉시 서비스를 이용할 수 있도록 두 곳에 웹 바로가기 버튼을 추가했다.

## 변경 내용

### 1. CSS — `.btn-block` 클래스 추가
기존 `.btn` / `.btn-primary` / `.btn-lg` 토큰과 `--primary` 변수를 재사용하는 풀폭 CTA 버튼 클래스 1개 추가.
- `width: 100%`, 상단 여백 12px, 패딩/폰트를 `.btn-lg` 수준으로 확대.
- 호버 시 `translateY(-2px)` + 그림자 (기존 `.store-btn:hover` 톤과 일치).

### 2. 상단 Hero 영역 — "바로 시작하기" 풀폭 버튼
`.hero-buttons`(구글 | 애플 다운로드) 바로 아래에 추가.
```html
<a href="https://barorez.com/app" class="btn btn-primary btn-lg btn-block">바로 시작하기</a>
```
- 자사 웹이므로 `target="_blank"` 없이 같은 탭 이동 (스토어 버튼만 새 탭 유지).

### 3. 하단 JOIN 영역 — "맛집바로 시작하기" 긴 버튼
`.join-grid`(사장님/고객 카드 2개) 아래 최하단부, `max-width: 800px` 중앙 정렬 박스로 배치.
```html
<a href="https://barorez.com/app" class="btn btn-primary btn-lg btn-block" style="margin-top:0;">맛집바로 시작하기</a>
```

## 검증
- 빌드/테스트 파이프라인 없음 → 브라우저 직접 확인.
- Hero 풀폭 버튼 표시 및 `https://barorez.com/app` 같은 탭 이동 확인.
- JOIN 영역 최하단 긴 버튼 표시 및 동일 URL 이동 확인.
- 모바일 폭(≤480px) 풀폭 표시 정상.

## 후속 수정 — Hero 버튼 폭 조정
초기 구현에서 Hero "바로 시작하기" 버튼이 `width:100%`로 Hero 콘텐츠 전체 폭(약 570px)까지 늘어나 과도하게 길어 보이는 문제 발생. 스토어 버튼(구글|애플) 묶음 폭에 맞춰 조정.

- `.hero-cta-group` 래퍼(`display: inline-flex; flex-direction: column`)로 `.hero-buttons`와 "바로 시작하기" 버튼을 함께 감쌈.
- 래퍼가 스토어 버튼 묶음 폭만큼만 차지 → 그 아래 버튼도 동일 폭으로 정렬.
- 모바일(≤768px)에서는 `.hero-cta-group { display: flex; width: 100% }`로 override해 기존 풀폭 유지.
- 결과 레이아웃:
  ```
  [구글 다운로드] [애플 다운로드]
  [       바로 시작하기        ]
  ```
- 하단 JOIN "맛집바로 시작하기" 버튼은 변경 없음(max-width 800px 박스 내 풀폭 유지).
