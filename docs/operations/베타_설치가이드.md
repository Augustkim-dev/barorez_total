# 영수증 자동 출력 베타 설치 가이드 (점주용)

> 본부에서 전달받은 **barorez-printer.exe** 와 **config.ini** 두 개 파일이 있다는 전제로 작성됨. 시간 기준 약 15분.

## 0. 필요한 것

- Windows 10 또는 11 이 설치된 매장 PC (영수증 프린터를 항상 연결해 둘 PC)
- USB 영수증 프린터 1대 (Sewoo / SAM4S / BIXOLON / Epson TM 시리즈 등 ESC/POS 호환)
- 본부에서 받은 두 개 파일:
  - `barorez-printer.exe`
  - `config.ini`

## 1. 영수증 프린터 드라이버 설치

1. 프린터 제조사 홈페이지에서 본인 모델용 **Windows 드라이버** 를 받아 설치합니다.
2. 프린터 전원을 켜고 USB 케이블로 PC 와 연결합니다.
3. Windows **설정 > Bluetooth 및 장치 > 프린터 및 스캐너** 에서 새로 추가된 프린터를 확인합니다.
4. 프린터에 표시된 정확한 이름을 메모 — 예) `BIXOLON SRP-330II`. 이 이름이 `config.ini` 의 값과 정확히 같아야 합니다.

## 2. 설치 폴더 만들기

1. `C:\barorez-printer` 폴더를 새로 만듭니다.
2. 본부에서 받은 **barorez-printer.exe** 와 **config.ini** 두 파일을 이 폴더 안으로 옮깁니다.

## 3. config.ini 확인 / 수정

`config.ini` 를 **메모장** 으로 엽니다 (마우스 우클릭 > 연결 프로그램 > 메모장). 아래 항목들이 들어있는지 확인하고, **printer 부분의 `name` 값** 을 1번에서 확인한 프린터 이름으로 수정합니다.

```ini
[server]
ws_url = wss://barorez.com/printsvc/ws
http_base = https://barorez.com

[client]
client_idx = (본부 발급 번호)
token = (본부 발급 토큰)
capabilities = kitchen
app_version = 0.1.0-d015

[printer]
name = BIXOLON SRP-330II      ; <-- 여기를 1번에서 확인한 이름으로
codepage = cp949
width = 48
escpos_codepage_id =
right_margin = 2
```

저장하고 닫습니다. **`[server]` 와 `[client]` 두 섹션은 본부에서 미리 작성해 둔 값을 그대로 둡니다** — 임의 수정 금지.

## 4. 첫 실행

1. `C:\barorez-printer\barorez-printer.exe` 를 더블클릭합니다.
2. **Windows SmartScreen 경고** 가 나오면:
   - "추가 정보" 클릭 → "실행" 버튼이 나타납니다.
   - 본 프로그램은 본부가 자체 제작한 베타용 도구라 디지털 서명이 없습니다. 정식 코드 서명은 본 제품 출시 시점에 추가됩니다.
3. 잠시 후 화면 우측 하단 작업 표시줄(시간 옆) **트레이 영역에 동그라미 아이콘** 이 표시됩니다.
4. 아이콘 색상:
   - **초록** — 정상 연결, 작업 대기 중 ✅
   - **노랑** — 인터넷 연결 확인 중 (자동 재접속)
   - **빨강** — 토큰 또는 프린터 오류 (본부 연락 필요)

## 5. 자동 시작 등록 (PC 부팅 시 자동 실행)

매번 손으로 실행하지 않아도 되도록 자동 등록합니다.

1. **Win + R** 키 → `cmd` 입력 → 엔터
2. 다음 명령을 한 줄씩 입력 (PowerShell 도 동일):

```cmd
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v barorez-printer /t REG_SZ /d "\"C:\barorez-printer\barorez-printer.exe\"" /f
```

3. 이제 PC 가 재부팅되면 트레이에 자동으로 뜹니다.

> 해제: 같은 명령에서 `add` 를 `delete` 로 바꿔 `reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v barorez-printer /f` 입력.

## 6. 작동 확인

1. 본부에 연락하여 **테스트 주문 1건 발송** 을 요청합니다.
2. 영수증 프린터에서 자동으로 영수증 1장이 나와야 합니다.
3. 트레이 아이콘 우클릭 → **"최근 출력"** 메뉴에 1줄 추가되어 있으면 정상.

## 7. 평소 운영

- 매장 PC 를 켜 두기만 하면 자동으로 작동합니다. 별도 조작 불요.
- 인터넷 연결이 잠시 끊겼다 복구되어도 그동안 발생한 주문은 자동으로 일괄 출력됩니다.
- 영수증 용지가 떨어지거나 프린터 전원이 꺼지면 트레이 아이콘이 **빨강** 으로 바뀝니다 — 용지/전원 확인 후 자동 복구됩니다.

## 8. 자주 묻는 문제

| 증상 | 확인 |
|---|---|
| 트레이 아이콘이 보이지 않아요 | 작업 표시줄 트레이의 ^ 화살표 클릭 — 숨겨진 아이콘 영역에 있을 수 있음. |
| SmartScreen 경고가 계속 나와요 | 4-2번 참조. 한 번 "실행" 누르면 다음부터 나오지 않습니다. |
| 한글이 깨져 나와요 | 본부에 프린터 모델명을 전달 — `config.ini` 의 `codepage` 또는 `escpos_codepage_id` 값을 조정해야 합니다. |
| 영수증이 너무 오른쪽으로 붙어 나와요 | `config.ini` 의 `right_margin` 값을 `2` → `3` 또는 `4` 로 늘리고 재실행. |
| 영수증이 안 나와요 | 트레이 아이콘 우클릭 → **"상태 확인"** 으로 색상 확인. 빨강이면 본부 연락. 초록이면 본부에 주문 발생 여부 재확인 요청. |
| 프린터 이름이 바뀌었어요 (드라이버 재설치 등) | `config.ini` 의 `[printer] name` 을 새 이름으로 수정 후 트레이 아이콘 우클릭 → "재연결". 또는 PC 재시작. |

- [ ] `client_python/build.bat` 로 `barorez-printer.exe` 빌드 (D015)
- [ ] `tools/register_client.py` 로 해당 매장 client 등록 → `config.ini` 생성
- [ ] `config.ini` 의 `[printer].name` 만 비워두고 점주가 채우도록 안내
- [ ] 두 파일 (exe + config) 을 USB 또는 클라우드 링크로 점주에 전달
- [ ] 점주가 5-6번 단계를 마치면 본부 대시보드(또는 DB 직접 조회)로 `print_job_t` 처리 확인
